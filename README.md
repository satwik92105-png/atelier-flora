# 🌸 Atelier Flora - Handcrafted Botanical Art & Artisan Crafts

A botanical e-commerce and portfolio website created for an artisan craft designer. Features real pressed-flower resin art, wildflower embroidery hoops, handcrafted crochet bags, botanical candles, and ceramic dishes — accompanied by a flowery aesthetic with drifting petal animations, and full legal compliance.

---

## 💻 How to Start the Website Locally

### Option 1: 1-Click Launch (Recommended)
Double-click **`start_website.bat`** inside this folder.
- Starts the Python SQLite backend.
- Automatically opens `http://localhost:8080` in your web browser.

### Option 2: Run via Terminal
```powershell
python server.py
```

### Option 3: Direct Browser Open
Double-click `index.html` to open directly in any web browser without running a server.

## 🌐 How to Upload to GitHub Pages

1. Open your repository on **GitHub.com**.
2. Click **Add file** → **Upload files**.
3. Select all files inside this folder (`index.html`, `style.css`, `app.js`, `products.js`, `README.md`).
4. Drag and drop them directly onto GitHub.
5. Click **Commit changes**.
6. Go to **Settings** → **Pages** → Branch: `main` → Folder: `/(root)` → Click **Save**.
